# Sukesh Forge — portfolio

3D-style portfolio: node-globe hero (canvas, real 3D maths), pull-cord dark/light switch, tilt cards,
3D tools ring, services (software only), small-business systems (hospital, hotel, gym, boutique, more),
and a contact form that emails you directly.

- No build step, no dependencies. Double-click `index.html` to preview.
- Edit `js/config.js` (email + Web3Forms key) and `js/data.js` (all text).
- Deploy: see `DEPLOY.md`.

Structure: `index.html` · `css/styles.css` · `js/{config,data,main,globe,cord}.js` · `assets/favicon.svg` · `404.html`
